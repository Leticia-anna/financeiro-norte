Adicionar outro assessor à equipe

Por segurança, novos acessos ainda são criados diretamente no painel do Supabase (não existe cadastro público neste app). Para adicionar um colega:

1. Acesse o painel do Supabase deste projeto → Authentication → Users → Add user.
2. Preencha o e-mail e uma senha temporária para a pessoa.
3. Um perfil de assessor é criado automaticamente para ela assim que o primeiro login for feito.

Sobre os dados

Este ambiente está usando dados fictícios de teste, como combinado — ainda não há informações reais de clientes conectadas. Quando fizer sentido avançar para dados reais, vale envolver o time de compliance/segurança antes de conectar qualquer informação real de clientes.
